# Как использовать шаблон:
# 1. Скопируйте этот файл в _texts/nazvanie.md, без даты в имени.
# 2. Заполните название и замените пример своим текстом в Markdown.
#    Для кнопки «К произведению» в поле work задайте имя файла карточки
#    из _works без .md, например work: "nazvanie". Если поле пустое,
#    используется имя самого файла текста. Карточка должна быть опубликована.
# 3. Задайте количество видимых строк страницы: lines_per_page_desktop для ПК,
#    lines_per_page_mobile для экранов шириной до 600 пикселей включительно.
#    Нужны положительные целые числа. Разделители страниц не используются.
#    Переносы строк исходного файла не задают границы страниц.
#    Разбиение пересчитывается по ширине окна после загрузки шрифта.
#    Каждая новая строка обычного текста — новый абзац с красной строкой.
#    Перенос по ширине редактора новой строкой исходника не считается.
#    Пустые строки вокруг горизонтальной черты сохраняются при чтении.
# 4. Установите published: true для включения текста в сборку.
#    false исключает текст из сайта, но не скрывает исходник в публичном Git.
# 5. Адрес чтения: /nazvanie/text/, следующие страницы — /nazvanie/text/?page=2.
#    Необязательный permalink: /drugoy-adres/text/ меняет адрес чтения.
#    Адрес должен начинаться и заканчиваться /; используйте буквы, цифры, - и _.
# 6. В карточке произведения (_works/nazvanie.md) задайте
#    read_url: "/nazvanie/text/". Для ссылок и изображений используйте пути
#    от корня сайта. Для автоматического разбиения нужен JavaScript в браузере.
# Необязательное поле date с будущей датой отложит появление текста.
